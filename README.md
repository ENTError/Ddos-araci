# Ddos-arac-
Bu Toolla Ddos atmak artık çok kolay :) Kullanımı aşırı basit ve güvenlige önem veren bir tooldur. Toolun kullanımı için Tor yüklemeniz gerekmektedir.

## Kurulum
1. Gerekli kütüphaneleri yükleyin:
pip install pysocks colorama
2. Tor'u başlatın:
tor
3. Aracı çalıştırın:
python ddos_araci.py
- Ardından, prompt'lardan hedef IP, port ve süreyi girin.

## Gereksinimler
- Python 3.x
- Tor kurulu olmalı

## Uyarı
Bu aracı yasal amaçlar için kullanın.
